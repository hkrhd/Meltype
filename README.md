# Meltype（個人フォーク）

[yksr-melt/Meltype](https://github.com/yksr-melt/Meltype) をもとに、Mac の変換精度と記号入力を調整したフォークです。

## 主な機能・変更点

- Mac の漢字変換に Zenzai small v3.2（Metal）を使用。同音異義語はモデルと辞書の候補から選択できます。
- 英単語の補完候補を英語判定前でも英字3文字から表示。Mac・Windows とも Tab／Shift+Tab で選び、Enter または続けての入力で確定できます。Mac はクリックにも対応します。
- 日英の区切り判定、最後の文節からの予測、あいさつの補完、括弧候補、8桁の日付候補を取り込み。Mac の画面移動後の候補表示、矢印キー、辞書取込画面も修正されています。
- macOS のテキスト置換をユーザー辞書へ自動同期し、変更後の画面スリープ時に再読込します。macOS 側の登録を正として、Meltype 側の独自登録も置き換えます。
- 日本語の途中では、かなで読める語の英字学習だけで文を分断しません（`プロンプtotoして → プロンプトとして`）。英単語・英文中の学習は維持します。
- 英字の後ろの助詞や、短い英単語に続く日本語を維持します（`mainno → mainの`、`macnanode → macなので`）。小文字の `no` は「の」と表示し、Space で英語の `no ` を確定します。
- ユーザーが英語辞書に登録した単独の語は英字を優先。日本語の語の途中は分断しません。また、ユーザー辞書の短い読みで長い語や送り仮名を分断する誤変換を抑えます。
- 文中で変換エンジンがかなのまま残した部分は、学習で自動上書きしません。単独入力の学習と候補の選び直しは維持します。
- 日数・回数の途中を英字にしません（`1niti1kai → 1日1回`）。`2kani` などには、ほかの意味を残して「日に」の候補も表示します。
- `lじ`（`lji`）は「L字」を先頭候補にします。ショートカット表記はかなにせず、修飾キーだけ大文字にします（`c-s-a → C-S-a`）。
- `.` は直前がかな・漢字・長音なら `。`、それ以外は半角で入力します。未確定・確定済みの両方に対応します。
- `$`・`"`・バッククォート・`_`・`/` は半角を維持し、未確定の語がなければ即確定します。`#`・`-`・`~`・`+`・`&` だけの入力に続く Space は、記号と半角空白を確定します。
