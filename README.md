# Meltype（個人フォーク）

[yksr-melt/Meltype](https://github.com/yksr-melt/Meltype) のフォークです。upstream の `main` に追従します。

## 主な変更

- mac向け
- zenzaiによる変換精度向上
- mdやターミナルでよく使う記号などを半角に

## 変更点：

- macOS のユーザ辞書の変更監視・`userdict.txt` への自動同期を Meltype 本体に統合。dotfiles の常駐処理は不要。変更は画面スリープ時に再読込。
- ユーザーの `dictionaries/english.txt` に登録した単独の語は英字を優先（`sudo` が `すど` になる問題を修正）。日本語の単語の途中は分断しない。
- Macの検証時はXcode本体を起動せず、追加コンポーネントのインストール画面が出るのを防止。
- ユーザー辞書が単語の途中を分断する誤変換を修正（例：`かん → 燗` の登録で `かんきせん → 燗汽船` になる問題）。
- 送り仮名も単語の一部として保護し、`かん → 燗` の登録があっても `もたつく感じはある` を `もたつく燗事はある` にしない。
- 英語として学習した `n` で終わる語に助詞「の」を続けたとき、末尾の `n` を英単語に残す（`mainno → mainの`）。
- そのまま日本語を続けても助詞「の」を維持（`mainnoyousuwomite → mainの様子を見て`）。
- 小文字の `no` は学習・ユーザー辞書によらず「の」を表示し、Space で区切ったときに英語の `no ` を確定。
- `.` は直前がかな・漢字・長音なら `。`、それ以外は半角の `.` を入力（未確定・確定済みの両方に対応）。
- `#`・`-`・`~`・`+`・`&` だけを入力した直後の Space は、変換せず記号と半角空白を確定（`##`・`~~~` などの連続入力も対応）。
- `$`・`"`・バッククォート・`_`・`/` は変換対象にせず半角を維持。未確定の語がないときは、押した時点で即確定。
- Zenzai small（Metal、評価上限2回）を使用。
- Mac の候補一覧では通常入力と別の変換状態でモデル評価・辞書探索の候補を併記し、「しじする → 指示する・支持する・師事する」などの同音異義語を選べるよう改善。
- フォーク独自の追加テストは [tests/fork](tests/fork/) と Swift 用の `mac/Tests/ForkMacTests` に置き、upstream のテストと区別。
- GitHub Actions は `upstream-update` と `zenzai-update` で12時間ごとに更新を確認し、取り込み・モデル更新依頼の Draft PR を作成。upstream 由来のビルド・配布・bot用Actionsは停止し、検証・適用はローカルMacで行う（[運用手順](docs/FORK.md)）。
