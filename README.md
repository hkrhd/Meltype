# Meltype（個人フォーク）

[yksr-melt/Meltype](https://github.com/yksr-melt/Meltype) のフォークです。upstream の `main` に追従します。

変更点：

- ユーザー辞書が単語の途中を分断する誤変換を修正（例：`かん → 燗` の登録で `かんきせん → 燗汽船` になる問題）。
- 送り仮名も単語の一部として保護し、`かん → 燗` の登録があっても `もたつく感じはある` を `もたつく燗事はある` にしない。
- `.` は直前がかな・漢字・長音なら `。`、それ以外は半角の `.` を入力（未確定・確定済みの両方に対応）。
- `#`・`-`・`~`・`+`・`&` だけを入力した直後の Space は、変換せず記号と半角空白を確定（`##`・`~~~` などの連続入力も対応）。
- `$`・`"`・バッククォート・`_`・`/` は変換対象にせず半角を維持。未確定の語がないときは、押した時点で即確定。
- Mac の変換に Zenzai small（Metal、ニューラル評価上限2回）を使用。
- Mac の候補一覧では通常入力と別の変換状態でモデル評価・辞書探索の候補を併記し、「しじする → 指示する・支持する・師事する」などの同音異義語を選べるよう改善。
- フォーク独自の追加テストは [tests/fork](tests/fork/) に集約し、upstream のテストと区別。
- upstream の取り込みは Codex が独自の挙動・方針との整合を確認して調整する（[運用手順](docs/FORK.md)）。
